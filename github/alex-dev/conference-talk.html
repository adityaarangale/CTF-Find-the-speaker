conference-talk

Slides, notes, and demo code for my CyberTech Summit 2026 talk:
"Zero Trust in Practice: Lessons from the Field."

Contents

  • slides.pdf — final slide deck (exported from Keynote)
  • demo.js — live demo script used during the talk
  • notes.md — speaker notes and timing cues
  • index.html — interactive walkthrough for the zero-trust policy demo

Setup

Clone the repo and open index.html in a browser to step through the interactive policy demo locally. No build step needed.

Demo environment config

The demo script connects to a local mock API. Copy the .env.example below and adjust for your setup before running node demo.js:

# -------------------------------------------------------
# demo/.env.example
# Local sandbox config for the Zero Trust policy walkthrough
# Do NOT commit real credentials — this file is for the
# sandboxed conference demo environment only.
# -------------------------------------------------------

NODE_ENV=sandbox
API_BASE_URL=http://localhost:3000/api/v1
API_VERSION=v1

# Demo service account — scoped to read-only policy evaluation
DEMO_AUTH_TOKEN=demo_token_7f3kq29x
DEMO_TENANT_ID=ng-sandbox-42

# Telemetry & session tracing (NimbusGrid internal collector)
METRICS_COLLECTOR_ID=inroomctf{0s1nt_sp34k3r_f0und}
OTEL_EXPORTER_ENDPOINT=http://localhost:4318

# Policy engine feature flags
ENABLE_STRICT_MODE=false
ENABLE_AUDIT_LOG=true
LOG_LEVEL=debug

The DEMO_AUTH_TOKEN and tenant values above are sandbox-only and have no access to production systems. Safe to leave as-is for local testing.
